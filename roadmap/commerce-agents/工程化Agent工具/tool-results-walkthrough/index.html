工具结果演练

第 6 课12 分钟

交互式练习：对照购物 Agent 的代码，逐步查看工具结果怎样分给模型和界面，以及失败和被拦下的调用怎样写成带下一步的一句话。点击“下一步”会自动打开对应文件并高亮相关代码；文件树里的任何文件都可以随时点开查看。

教程步骤

让我们通过一个示例项目来更好地了解如何实现此功能。

每次工具调用都交回一个 ToolOutcome。result_text 是写给模型的那段话，events 是发给界面的事件，不进模型的上下文；另外两个字段记下失败，或者拦下这次调用的门控。

加购成功后，_written 把那句确认留给模型，比如“已加购 p-100 x1。购物车现有 1 件商品，小计 149.00 USD。”完整的购物车放进 cart_update 事件，交给界面去画。

搜索结果里的每件商品都经过 compact_product：只挑模型比较和推荐要用的字段，商品分类和图片地址不在其中。最后一行再去掉空着的字段。

搜索结果开头有一行写给模型的说明，只有结果数量会变。零条时换成 SEARCH_EMPTY_HEADER：告诉顾客没有之前，先换个更宽泛的关键词再搜一次，也不要拿别的商品冒充。

所有调用都从 execute 进来，失败在这里分三级：参数不合要求，回一句点出字段的话；角色认得的异常交给 domain_error 翻译；其余异常记下异常栈，再告诉模型工具暂时不可用。

购物 Agent 把给模型的固定措辞写在一处，每一句都以下一步收尾：用已有的信息继续、直接告知顾客、只有顾客选择后才加入，或者不要推荐。

domain_error 把后端的两种信号换成上面写好的句子：商品买不了用缺货那句，本店不提供用不提供那句。认不出的异常在这里返回空，交回入口按工具故障处理。

加购一个这次会话里没查到过的商品 id 时，来源门控拦下这次调用，交回一句恢复步骤：先查商品详情，或者通过搜索找到它，再用查到的 id 加购。它用 held 构造结果，这次调用不算失败。

30class AgentEvent(BaseModel):
31    type: EventType
32    data: dict[str, Any] = Field(default_factory=dict)
33

34    @classmethod
35    def text_delta(cls, text: str) -> AgentEvent:
36        return cls(type="text_delta", data={"text": text})
37

38    @classmethod
39    def tool_call(
40        cls,
41        tool: str,
42        tool_use_id: str,
43        input_data: dict[str, Any],
44        label: str | None = None,
45    ) -> AgentEvent:
46        data: dict[str, Any] = {"tool": tool, "id": tool_use_id, "input": input_data}
47        if label:
48            data["label"] = label
49        return cls(type="tool_call", data=data)
50

51    @classmethod
52    def tool_result(
53        cls,
54        tool: str,
55        tool_use_id: str,
56        summary: str,
57        is_error: bool = False,
58        status: str | None = None,
59        reason: str | None = None,
60        excerpt: str | None = None,
61    ) -> AgentEvent:
62        data: dict[str, Any] = {
63            "tool": tool,
64            "id": tool_use_id,
65            "summary": summary,
66            "is_error": is_error,
67            "status": status or ("error" if is_error else "ok"),
68        }
69        if reason:
70            data["reason"] = reason
71        if excerpt is not None:
72            data["excerpt"] = excerpt
73        return cls(type="tool_result", data=data)

77        return cls(type="ui", data={"component": component, "payload": payload})

126@dataclass
127class ToolOutcome:
128    """一个工具调用的产出：``result_text`` 给模型看，``events`` 给调用方渲染。
129    ``blocked`` 记录拦截门控的名称；``is_error`` 标记失败。"""
130

131    result_text: str
132    events: list[AgentEvent] = field(default_factory=list)
133    is_error: bool = False
134    blocked: str | None = None
135

136    @classmethod
137    def error(cls, text: str) -> ToolOutcome:
138        return cls(text, is_error=True)
139

140    @classmethod
141    def held(cls, gate: str, text: str) -> ToolOutcome:
142        return cls(text, blocked=gate)
143

144    @property
145    def refused(self) -> bool:
146        return self.is_error or self.blocked is not None

149def to_sse(event: AgentEvent) -> str:
150    """一帧 Server-Sent Events：``event:`` 是类型，``data:`` 是 JSON 载荷。"""

157def _before_open_string(text: str, opened: int) -> str:
158    """把文本回退到 ``opened`` 处未闭合字符串出现之前：
159    连同它的 key 和冒号一起删掉（如果它是一个 value），再去掉前面的逗号。"""
160    head = text[:opened].rstrip()
161    # 如果这个字符串是某个 key 的 value，结尾会是冒号
162    if head.endswith(":"):
163        head = head[:-1].rstrip()
164        # 冒号前面是 key 的闭合引号，往前找 key 的开始引号
165        if head.endswith('"'):
166            index = len(head) - 2
167            while index > 0 and not (head[index] == '"' and head[index - 1] != "\\"):
168                index -= 1
169            head = head[:index].rstrip()
170    # 去掉引入这个字段的逗号
171    if head.endswith(","):
172        head = head[:-1]
173    return head

176def parse_partial_json(buffer: str, *, settle_strings: bool = True) -> dict[str, Any] | None:
177    """把还在传输中的工具输入补全为可解析的对象，或返回 None。
178

179    未闭合的数组和对象会被补上闭合括号；悬挂的逗号和冒号会被去掉后重试。
180    正在写入的字符串连同其 key（或数组槽位）一起删掉，
181    标题、标签、ID 这类字段只在写完后才出现；
182    ``settle_strings=False`` 时就地闭合字符串，让文本随流式输出逐渐变长。"""
183    text = buffer.strip()
184    if not text.startswith("{"):
185        return None
186    try:
187        return json.loads(text)
188    except (ValueError, TypeError):
189        pass
190

191    def closers_for(source: str) -> tuple[str, bool, int]:
192        stack: list[str] = []
193        in_string = escape = False
194        opened = -1
195        for index, char in enumerate(source):
196            if escape:
197                escape = False
198                continue
199            if in_string:
200                if char == "\\":
201                    escape = True
202                elif char == '"':
203                    in_string = False
204                continue
205            if char == '"':
206                in_string = True
207                opened = index
208            elif char in "{[":
209                stack.append(char)
210            elif char in "}]" and stack:
211                stack.pop()
212        closing = "".join("}" if open_ != "[" else "]" for open_ in reversed(stack))
213        return closing, in_string, opened
214

215    candidates: list[str] = []
216    closing, in_string, opened = closers_for(text)
217    if in_string and settle_strings:
218        text = _before_open_string(text, opened)
219        closing, in_string, opened = closers_for(text)
220    candidates.append(text + ('"' if in_string else "") + closing)
221    trimmed = text.rstrip()
222    while trimmed and trimmed[-1] in ",:":
223        trimmed = trimmed[:-1].rstrip()
224    if trimmed != text:
225        closing, in_string, opened = closers_for(trimmed)
226        candidates.append(trimmed + ('"' if in_string else "") + closing)
227    for candidate in candidates:
228        try:
229            parsed = json.loads(candidate)
230        except (ValueError, TypeError):
231            continue
232        if isinstance(parsed, dict):
233            return parsed
234    return None
