# 工程化 Agent 工具

专题：从一个工具的定义讲到展示型工具，看购物 Agent 怎样把工具建在商店已有的系统上，并在执行器里守住写入、读取和展示的边界。

这个专题不跟着各个 Stage 的步骤走，而是横着看购物 Agent 的全部工具。每一课都从原型店铺里的一件商品讲起（原型店铺是测试和本地原型共用的假后端，只有五件商品）：一次搜索怎样穿过工具边界，结果怎样写给模型，购物车写入怎样被门控，第三方文案怎样被关进围栏，界面组件为什么也是工具。最后一篇是概念评估。

开始之前，建议先读前言里的[《为 Agent 编写高效工具》](../../前言/为Agent编写高效工具/index.md)，以及《高效商务 Agent 架构指南》的[“工程化 Agent 工具”](../../前言/高效商务Agent架构指南/index.mdx#工程化-agent-工具)一节，再读路线的[《循环与第一个工具》](../一个文件，一段对话/01-the-agent-loop.mdx)。

## 学习目标

- 区分工具定义里写给模型的约束，和执行器里真正执行的检查
- 解释工具列表为什么顺序固定、只随部署配置变化
- 判断一段逻辑应该放在工具里、后端里，还是交给模型
- 设计写给模型的工具结果：只留推理要用的字段，失败时写明下一步
- 说明来源门控、选项门控和数量上限怎样守住购物车写入
- 解释围栏怎样把第三方文本变成数据，以及模型被骗之后还剩哪些防线
- 说明展示型工具为什么只收 ID，由服务端填写商品事实
