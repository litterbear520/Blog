# 出图规范

## 什么时候画、用什么画

- 谁把什么交给谁、按什么顺序：`MessageFlow`（见 [组件怎么选](components.md)）。
- 一次运行随时间推进：`AgentLoopViz`。
- 结构、分层、边界、循环：自己画 SVG 组件。布局复杂时先用 diagram-design 技能出稿，再改写成 JSX，颜色全部换成下面的变量。
- 文字一句话就能说清的，不画。

## 配色：按角色，不按“当前 / 非当前”

| 角色 | 变量 | 用在 |
| ---- | ---- | ---- |
| 中性 | `--th-dg-neutral` | 输入、上下文、容器标题带 |
| 处理 | `--th-dg-process` | 模型、执行器、循环里的步骤 |
| 完成 | `--th-dg-done` | 成功、放行、结束 |
| 外部 | `--th-dg-external` | 用户、人工介入、第三方系统 |
| 容器底 | `--th-dg-body` | 容器主体 |
| 描边 / 连线 | `--th-dg-stroke` | 节点描边、主连线 |
| 回路 | `--th-dg-loop` | 回路、次要路径 |
| 文字 | `--th-dg-text` | 节点里的字 |
| 结论框 | `--th-accent-border` + `--th-accent-tint` | 每张图至多一个 |

变量在 `src/css/custom.css`，深浅两套，节点里的文字对比度都在 5:1 以上。

## 画法

- **布局**：主流程从左到右一条轴，输入在最左、结果在最右；人工介入、配置这类旁路从下方接进来；回路画成主轴下方的直角折线；同一边界里的步骤装进一个容器，容器顶部一条标题带。
- **线与箭头**：直线和直角折线，开口 V 形箭头；主线 1.5–2px，回路同样粗细、换成回路色。
- **文字**：中文标签，节点名 14px、说明 12–13px，都不小于 12px；标签单行居中，代码名用等宽字体。
- **尺寸**：viewBox 宽 768（正文列宽），节点高 40–48，圆角 6–8，四周留白至少 16，坐标落在 4px 网格上。窄屏时横向滚动，不把整张图缩到字看不清。
- **组件写法**：照 `src/components/RoadmapOverview`：常量算坐标，CSS Module 里引用变量，`<svg role="img">` 带 `<title>` 和 `<desc>`。

## 图和正文

- 先文后图：图前一句以冒号结尾的引导句，图里每个元素都能在前文找到对应的一句。
- 复杂机制拆成几张递进图，每张只比上一张多一个元素；消息流用 `upTo` 做同样的事。
- `<desc>` 和 `summary` 写成一整句：“这张图说明……”。
- 图下不写图注，要解释的写进正文。
