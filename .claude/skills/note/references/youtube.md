# YouTube 频道讲稿

这份说明针对第三方 YouTube 频道的讲稿（目前都是“无限芝士”的节点、VPS、域名系列）。SKILL.md 的通用规则照用，下面几条是在它们之上多做的。这类讲稿不是用户本人讲的，但用户要的同样是讲者原话：只做最小替换，每处改动写进报告。

简介块和文末的参考视频（SKILL.md 第 3 步）所有 YouTube 视频都要放；频道话术、字幕核对这些只对第三方频道适用，画面没有烧录字幕就跳过核对那一节。

视频 ID 从用户给的链接里拿；没给就在引用这期视频的旧笔记里找（文末的“参考视频”、简介里的“第一期”这类链接）；都找不到再问用户。

## 正文替换

在 SKILL.md 第 2 步之外，再做这几条：

- **频道话术整句删**：开头自报家门（“这里是无限芝士”）、中间拉群（“欢迎加入 Telegram 群”）、结尾“频道以后会更新……”“欢迎关注”。这些话是说给视频观众听的，文章读者用不上。“频道整理了……”这类指路句保留，挂上对应的链接；正文中间预告后续内容的句子（“这两种方法频道会单独出视频讲解”）是讲解的一部分，也保留，已经有对应的视频就把链接挂上。
- **“观众”改成“读者”**，和“视频→文章”同一个道理。只对视频成立的动作（“拖动进度条”）换成文章里的等价说法（“往下翻”），报告里列出来。
- **指着画面的句子照留**：“结果如图”“出现这个界面就说明连接成功”不删，也不配截图。截图很快会过时，讲稿本身已经把结果说出来了。
- **段首的口播段落标记**（“购买 VPS。”“节点被墙。”）换成小标题以后删掉，免得小标题下面又重复一遍。
- **讲者的声明照留**：“这期视频不含任何广告”改成“这篇文章不含任何广告”后保留。简介块里的 aff 返利算不上赞助，用户确认过（2026-10-21）。
- **简介里作者的更正**（如“视频中的 Vircs 已不再运营住宅 VPS”）可以用 `:::info` 放在讲到它的那段后面，开头写“[简介](#简介)补充：”。这是“不加提示块”唯一的例外：不放的话，读者照着正文会去找已经停运的厂商。

## 引用其他几期

讲稿说“可以看我的这期视频 / 这期教程”，指的是同频道的另一期，不是本期，不能一律换成“这篇文章”：

- 站内已经有那期的笔记：“这期视频”改成“这篇文章”或“这篇教程”，链到那篇笔记的相对路径。
- 站内还没有：保留“这期”，链到 YouTube 原视频（地址从简介里拿），报告里列出来，用户可能要接着转写。
- 反向补链：新笔记上线后，旧笔记里指向本期视频的 YouTube 链接（如“建议看[第一期视频]”）改成链到新笔记，说法跟着换成“文章”。

## 链接和命令

- 正文里的厂商、工具挂官网，比如 [RackNerd](https://www.racknerd.com/)；简介里的 aff 链接只留在简介块里。
- 讲稿说“输入这串代码”“只需要这样一行命令”时，命令在简介里的文档上，多是 Notion 公开页。用浏览器打开会撞上人机验证，用脚本取：

  ```bash
  python3 .claude/skills/note/scripts/notion_code.py <简介里的 Notion 链接>
  ```

  照抄成 `bash` 代码块，放在讲到它的那一段后面。版本号照抄不改；和别的笔记版本不同时，在报告里提一句。
- 演示用的域名、站点名识别得不对劲时（“infinchacylink.top”），用 `dig`、`whois` 查真实记录来纠正（实际是在 NameSilo 注册的 `inficheesylink.top`）。

## 用烧录字幕核对识别错误

无限芝士的视频画面底部有烧录字幕，基本就是讲者的原话。数字、IP、英文专名这类光看上下文改不出来的疑点，去字幕里核对。这样改出来的有“18.2.20.2.”→“182、202”、“Allan”→“Arelion”、“对它来说”→“对他来说”。

这一节在正文写完、简介放好（SKILL.md 第 2–4 步）之后再做：估时刻要用写好的笔记和简介里的章节时间戳。

1. 估时刻。锚点取简介的章节时间戳，配上该章在正文里的头一句：

   ```bash
   python3 .claude/skills/note/scripts/locate.py <笔记> --video <视频 ID> \
     --at "VPS 本质就是一台海外电脑=34" --at "高端 VPS 厂商不少=434" "疑点里的几个字"
   ```

   最后一章之后按语速外推；知道视频总长时加 `--end <秒数>` 会更准。

2. 截帧拼字幕条，用 Read 打开拼图读原话。几个疑点一次传进去（重叠的时间段只截一次，少 seek 几次就晚一点被限流），命令放后台跑，要几分钟：

   ```bash
   uv run --no-project --with pillow python .claude/skills/note/scripts/subtitle_frames.py <视频 ID> <秒数>... --out <scratchpad 下的目录>
   ```

3. 字幕和讲稿对不上时：字幕对，就按字幕改，报告里注明“对照字幕”。字幕本身也会错（字幕写“此时未弹出套餐”，上下文是“会弹出”），和上下文冲突时按上下文。字幕里就是讲者用词的（“专有名字”“会员线路”）照留，那是原话，不是识别错误。
4. 截帧脚本以退出码 3 结束，说明 YouTube 在限流，当天就别再试了。把剩下的疑点交给用户去听，报告里写原文、你的猜测和 `locate.py` 给的带时间链接。

## 报告里多写

- 对照字幕改过的地方，以及核对后保留原样的地方；
- 没能核实的疑点：列成“原文 / 猜测 / 带时间的链接”三列的表格，请用户去听。
