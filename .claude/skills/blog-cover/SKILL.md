# 博客封面

目标文章：$ARGUMENTS（为空时取 `blog/` 里日期最新的一篇，并告诉用户你选了哪篇）。

一张封面 = 一句视觉隐喻 + 一个底色 + 一个配方文件。渲染由 `npm run cover` 在 Node 里完成，不需要浏览器。
原语和母题的参数以 `tools/covers/README.md` 为准，动手前先读它；母题长相跑 `npm run cover -- --motifs` 后看 `tools/covers/.preview/motifs.png`。

## 这套风格长什么样

用户要的是和 claude.com/blog 封面**看不出区别**。那组封面每张只有两层：一层纸白剪纸块，一层墨黑毛笔线。之前的版本把它误读成“纸片 + 错位描边”，画出来像贴纸，和参考站一眼就能分出来。下面每条都是对着参考站十几张封面数出来的，偏离任何一条都会露馅：

- **纸片不描边，墨线画的是另一件东西。** 墨线画折线、连线、箭头、框架、光标，叠在纸片上面；纸片自己只是一块剪影。唯一的“轮廓”用法是两个同类物件错开叠放：一个只有墨线轮廓，另一个是纸白剪影（`m.bubble`）。
- **纸片是剪刀剪的。** 几段直边、转角微歪，圆形是看得出棱的八到十一边形（`d.cut` / `d.disc`）。不要撕纸毛边。
- **墨线约 20 粗，平滑、圆头，全图一个粗细。** 线宽按画布像素给，`d.at` 的缩放不会改变它，所以不用手动补偿。
- **不画手。** 参考站过半封面有手，但程序拼出来的手怎么调都僵、显得惊悚，用户已明确不要，母题库里也没有手。原本要靠手表达的动作换成物件和墨线：“点”用墨线光标（纸片上画轮廓，免得和纸白糊在一起），“递出 / 放出”用箭头或一跳一跳的墨线，“托着 / 拿着”直接让物件占满画面，或叠一张 `d.tint` 同类物件。
- **连接用黑点。** 折线、流程、网络的节点是实心墨点（`d.link`）或纸白剪纸圆（`m.network`），折线在节点处是硬转角；箭头是开口的 `<`（`d.arrow`）。墨线之间留空：箭头起点、虚线起点、光标尖离墨点至少一个线宽，贴在一起会糊成一团墨。
- **没有星芒、没有文字、没有界面细节。** 窗口圆点、代码符号、文字横线、数字都不画；概念靠几何块、墨线动作表达。
- **一个大物件顶住画面。** 参考站每张都有一个主物件（投影幕、书、台阶、网络、气泡），最长边 650 以上，几乎顶到画布边；其他东西围着它、叠在它上面，不要隔着一片空白单独站着。几个小物件隔着空白散在画面里，缩到卡片大小就只剩一堆碎片。
- **画面撑满，但什么都不出画。** 主体组合的长边占画布 85–95%；线条、纸片都在画布内收尾，离边 10–60。参考站没有一根线被画布边切断——列表卡片里画布四周就是底色，切断的线看起来像渲染错误。
- **纸片之间留缝。** 两块纸白贴在一起会糊成一块；相邻纸片之间至少留 30 的底色，或者其中一块改用 `d.tint`（台阶、领奖台这种本来连在一起的物件，本就该画成一整块 `d.cut` 或纸白与 tint 交替）；墨线物件压在纸片上时别再带纸白底（如 `m.magnifier({ lens: false })`）。

## 步骤

1. **读文章，找隐喻。** 读 `blog/<slug>/index.md` 全文，找出文章的核心动作或矛盾，再从下面的构图里挑一种落地，写成一句话：
   - 物件 + 墨线动作：一块大纸片（订阅卡片、一本书、一个模块）上叠墨线光标、箭头，或一张 tint 同类物件错开叠放
   - 板面 + 墨线内容：投影幕、画架、窗口上画折线、乱线团、提示符
   - 几何块 + 连线 / 箭头：三角、方块、剪纸圆之间用黑点连线或箭头串起来（流程、编排、迁移）
   - 网络 / 图表：纸白连线 + 剪纸圆节点，或坐标轴 + 折线
   - 剪影 + 动作：纸白台阶 + 墨线一跳一跳往上；两只气泡一实一虚错开
   一张图至多两组东西（常见是“一个大物件 + 叠在上面的墨线”；板面上画的折线算进板面那一组）。先想清楚读者在列表里扫一眼能认出什么，再想它像不像文章：认不出的隐喻再贴切也没用。
   母题库没有的物件，先在配方里用 `d.cut` / `d.brush` / `d.link` 拼；同一物件第二次用到时再提为母题加进 `lib/motifs.js`（局部坐标以 (0,0) 为中心，标称尺寸 600–750）。
2. **选底色。** 文章在 `src/pages/bloglist.js` 里已经登记了 `swatch`（重做封面）就沿用它，除非用户要求换色——换色会连带改变列表里的深浅交替。新文章：读 `src/data/swatches.json`；排除 `src/pages/bloglist.js` 里已出现的 `swatch`，优先挑从未用过的；都用过时保证与相邻两篇文章不同色。深色（clay / plum / mineral / olive / fig / sky）与浅色（peach / oat / heather / cactus / coral）在列表里交替出现。
3. **写配方。** 复制 `tools/covers/recipes/example.js` 为 `tools/covers/recipes/<slug>.js`，填 `swatch`、`seed`、`draw(d, m)`。先画纸片、后画墨线（后画的压在上面）。用 `d.at({ x, y, s, rot, flip }, () => ...)` 摆位，母题可以旋转、放大、镜像；出画的部分靠位置和缩放收回来，贴边的长线可以给 `d.brush` 加 `trim`。
4. **渲染并看图。** 运行 `npm run cover -- <slug> --preview`：终端会打印图形范围和越界点数，`tools/covers/.preview/<slug>.png` 是 1000² 画布，`<slug>-card.png` 是列表卡片里的样子。Read 画布图，再跑 `npm run cover -- --sheet` 看它和其他封面放在一起是否统一。逐项核对：
   - 扫一眼能认出物件，也能和文章主题对上
   - 主物件最长边 650 以上，画面里没有大片空着的象限
   - 没有手
   - 纸片没有描边、没有星芒、没有文字或界面细节
   - 墨线都压在纸片上面，粗细一致
   - 终端显示“无越界”，且没有任何 ⚠（越界、贴边、长边不到 85% 都会打 ⚠）
   - 纸片之间没有粘连成一块

   任一项不过就改坐标 / 缩放 / 换 seed，重渲再看；全部通过才进入下一步。
5. **登记。** `src/pages/bloglist.js` 的 POSTS 对应条目加 `swatch: '<名>'` 和 `cover: '/img/blog/cover-<slug>.svg'`；`tools/covers/README.md` 封面清单加一行（slug、底色、文件、配方）。重做封面时这两处已有登记，底色没换就不用动。
   完成标准：新文章的 `git status` 恰好出现配方、SVG、bloglist.js、README 四处改动（加了母题则多一处 `lib/motifs.js`）；重做封面只有配方和 SVG。

最后向用户报告：隐喻一句话、用的构图、底色、预览图路径。

## 环境提示

- 仓库 `node_modules` 可能是空的（本机装全量依赖会内存不足）。缺 `@resvg/resvg-js` 时别跑 `npm install`，在 scratchpad 里单独 `npm i @resvg/resvg-js`，再用 `NODE_PATH=<scratchpad>/node_modules node tools/covers/render.js <slug> --preview` 渲染。
