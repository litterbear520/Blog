## 术语
- Session → 会话；Next session → 下一个会话；Transcripts → 会话记录
- Dreaming → 做梦；second pass（第二轮做梦）→ 第二轮做梦

- memory store → 记忆存储；stateless baseline → 无状态基线；with memory → 使用记忆；no memory → 无记忆；raw memory → 原始记忆
- reward → 奖励；mean reward → 平均奖励；run(s) → 次运行；graded criteria → 评分项；graded facts → 评分事实
- 宝可梦官方中文名：Cerulean → 华蓝市；Pewter → 深灰市；Mt. Moon → 月见山；ledge → 台阶；cave → 山洞；PokéCenter → 宝可梦中心
