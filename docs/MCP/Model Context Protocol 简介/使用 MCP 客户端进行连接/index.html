使用 MCP 客户端进行连接

构建与 MCP 服务器通信的客户端一侧；实现用于直接访问数据的资源和提供预置指令的提示，看整个应用流程如何串起来。

实现客户端

现在我们的 MCP 服务器已经正常工作，接下来是构建客户端的时候了。客户端是让我们的应用程序代码能够与 MCP 服务器通信并访问其功能的部分。

定义资源

MCP 服务器中的资源（Resources）允许您向客户端公开数据，类似于典型 HTTP 服务器中的 GET 请求处理程序。它们非常适合需要获取信息而不是执行操作的场景。

访问资源

MCP 中的资源允许您的服务器公开可以直接包含在提示中的信息，而不需要通过工具调用来访问数据。这创建了一种更高效的方式来为 AI 模型提供上下文。

定义提示

MCP 服务器中的提示让您能够定义预构建的、高质量的指令，客户端可以使用这些指令，而不必从零开始编写自己的提示。可以将它们视为精心制作的模板，比用户自己想出来的效果更好。

客户端中的提示

构建我们的 MCP 客户端的最后一步是实现提示功能。这使我们能够列出服务器上所有可用的提示，并检索填充了变量的特定提示。
