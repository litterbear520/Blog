简介

从理解 MCP 的架构和它为什么存在开始：MCP 解决什么问题、服务器和客户端各做什么、消息如何在两者之间流动。

介绍 MCP

Model Context Protocol（MCP）是一个通信层，它为 Claude 提供上下文和工具，而无需您编写大量繁琐的集成代码。可以将其视为一种将工具定义和执行的负担从您的服务器转移到专门的 MCP 服务器的方式。

MCP 客户端

MCP客户端充当您的服务器与MCP服务器之间的通信桥梁。它是您访问MCP服务器提供的所有工具的入口点，负责处理消息交换和协议细节，这样您的应用程序就不必亲自处理这些事情。
