MCP

简介​

Model Context Protocol（MCP）是一个开放协议，用一套标准化的消息格式和传输方式，让 Claude 这样的语言模型可以通过 MCP 客户端与外部工具、数据源和文件系统打交道：服务器暴露工具、资源和提示，客户端负责连接、转发和呈现。

这一栏按课程组织 MCP 相关笔记：先看《Model Context Protocol 简介》，用 Python SDK 从零构建服务器和客户端，掌握工具、资源、提示三个原语；再看《高级主题》，学采样、通知、根目录和各种传输方式。每门课都有一个索引页说明本章要学什么，按索引页的课程内容顺序阅读即可。
