Model Context Protocol：高级主题

难度：高级12 课

超越 MCP 基础知识：采样、通知和根目录，并附有每个协议流程的交互式演练。

内容整理自 Claude Academy

本课程探讨 Model Context Protocol（MCP）开发的高级功能和实现模式，重点关注服务器-客户端通信、传输机制和生产部署注意事项。您将探索复杂的 MCP 功能，包括用于 AI 模型集成的采样、通知系统、文件系统访问控制，以及不同传输协议的技术细节。

学习目标​

  • 了解 MCP 服务器如何通过采样（sampling）通过已连接的客户端请求语言模型调用，从而将 AI 成本和复杂性从服务器转移到客户端
  • 使用上下文对象、日志记录回调和进度报告为长时间运行的操作实现实时反馈
  • 使用根目录（roots）授予 MCP 服务器访问特定目录的权限，同时具备安全边界和用户友好的文件发现功能
  • 区分 MCP 消息规范中的请求-结果对和通知消息，并理解双向通信模式
  • 了解 MCP 客户端和服务器如何通过标准输入/输出流进行通信，包括所需的初始化握手序列
  • 解释 Server-Sent Events（SSE）如何通过 HTTP 实现服务器到客户端的通信，包括会话管理和双连接架构
  • 识别配置标志如何影响功能，特别是服务器发起的请求和流式传输能力
  • 决定何时使用无状态 HTTP 以配合负载均衡器进行水平扩展，权衡有状态和无状态服务器配置之间的利弊
  • 根据部署需求、功能需求和扩展限制选择合适的传输方法

前提条件​

  • 具备 Python 开发和异步编程模式的经验
  • 熟悉 JSON 消息格式和 HTTP 协议
  • 具备 Server-Sent Events（SSE）的基础知识

本课程适合谁​

  • 从事 Model Context Protocol 实现工作的开发者
  • 构建 MCP 服务器和客户端的工程师
